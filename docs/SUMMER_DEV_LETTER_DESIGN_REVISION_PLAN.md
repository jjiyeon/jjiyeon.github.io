# Summer's Dev Letter 디자인 개편 계획

## 1. 요약

첫 Astro 구현에서는 콘텐츠 모델과 기본 라우팅을 검증했다.

다음 개편에서는 경험을 두 화면으로 단순화한다.

- `Letters`: 월별 개발레터 아카이브
- `About`: 이력서 기반 개인 프로필

목표는 일반적인 블로그/아카이브 느낌에서 벗어나, Summer의 기록 시스템처럼 보이는 미니멀한 개인 사이트를 만드는 것이다.

## 2. 결정 사항

- 상단 내비게이션은 `Letters`, `About`만 둔다.
- 브랜드/로고 영역은 로고가 준비될 때까지 비워둔다.
- `/`와 `/letters`는 최신 월 Letters 화면을 보여준다.
- Letters 탐색은 글 페이지 단위가 아니라 월 단위로 이동한다.
- 카테고리 필터는 별도 상위 메뉴가 아니라 Letters 화면 안에 둔다.
- About에는 원형 프로필 이미지 영역과 이력서형 섹션을 둔다.

## 3. Letters 경험

### 데스크탑

2열 레이아웃을 사용한다.

왼쪽 영역:

- `2026 May` 같은 현재 월 표시
- `Week 1` 같은 선택/강조 주차
- 월 이동 컨트롤
- 월/캘린더 정보 아래 카테고리 필터

오른쪽 영역:

- 해당 월의 주차별 개발레터 목록
- 한 달 기준 4-5개의 issue preview
- 각 개발레터 preview 상단에는 대표 이미지를 둘 수 있다.
- 가벼운 border와 명확한 위계 중심의 희박한 목록 스타일

전체적으로 카드형 블로그보다 캘린더/아카이브에 가까운 느낌이어야 한다.

### 모바일

단일 컬럼 레이아웃을 사용한다.

- 상단에 월 제목과 월 이동을 둔다.
- 카테고리 필터는 가로 스크롤 칩으로 보여준다.
- 주차별 개발레터 preview는 세로로 쌓는다.

데스크탑의 사이드바는 모바일에서 compact한 월 헤더로 바뀐다.

## 4. About 경험

About은 이력서 기반이지만 개인적인 결이 남아 있어야 한다.

권장 섹션:

- Profile: 원형 이미지, 이름, 역할, 짧은 소개, 링크
- Work: 경력과 경험
- Projects: 주요 프로젝트, 역할, 기술, 기여
- Expertise: frontend, collaboration, product thinking
- Now: 현재 관심사와 학습 중인 것

프로필 이미지 경로:

```txt
public/images/profile.jpg
```

이미지가 없으면 깨진 이미지 대신 단순한 원형 placeholder를 보여준다.

## 5. 레터 이미지 관리

개발레터는 글과 이미지를 한 폴더에서 관리한다.

```txt
src/content/letters/2026/05/week-1/
  index.md
  cover.jpg
  inline-flow.png
```

- `cover`: Letters 목록과 상세 상단에 사용하는 대표 이미지
- `coverAlt`: 대표 이미지 대체 텍스트
- 본문 이미지는 Markdown에서 `./inline-flow.png`처럼 상대 경로로 참조

대표 이미지가 없는 글은 이미지 영역을 숨긴다. 깨진 이미지나 빈 이미지 박스는 보여주지 않는다.

## 6. 구현 단계

1. `BaseLayout` 내비게이션에서 브랜드 텍스트를 제거하고 `Letters`, `About`만 남긴다.
2. 현재 홈 화면을 최신 월 Letters 화면으로 교체한다.
3. 연도/월/주차 기준으로 개발레터를 묶는 helper를 추가한다.
4. `/letters/[year]/[month]`를 만들고 `/letters`는 최신 월을 보여주게 한다.
5. 카테고리 필터를 Letters 월별 화면 안으로 옮긴다.
6. 독립적인 카테고리/태그 라우트는 주요 UX에서 숨기거나 제거한다.
7. 레터별 폴더 구조와 대표 이미지 표시를 적용한다.
8. About을 프로필 이미지와 이력서 기반 섹션으로 재디자인한다.
9. 전역 CSS를 카드 중심에서 얇은 선과 희박한 목록 중심으로 정리한다.
10. 데스크탑과 모바일 레이아웃을 확인한다.
11. `npm run build`를 실행한다.

## 7. 완료 기준

- 헤더에는 `Letters`, `About`만 보인다.
- 헤더에 텍스트 로고가 보이지 않는다.
- `/`와 `/letters`는 최신 월 개발레터 화면을 보여준다.
- 월 이동은 월 단위로 동작한다.
- 카테고리 필터는 월별 개발레터 목록에 적용된다.
- 대표 이미지가 있는 레터는 목록과 상세 상단에 이미지가 보인다.
- 본문 이미지는 레터 폴더 안의 상대 경로로 렌더링된다.
- About에는 원형 프로필 이미지 영역과 이력서형 콘텐츠 섹션이 있다.
- 모바일은 단일 컬럼이며 사이드바에 의존하지 않는다.
- `npm run build`가 성공한다.
